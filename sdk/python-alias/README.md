# autonomo-sdk (Python)

Another name for the Autonomo Python SDK, so the install matches the TypeScript one. It holds no code of its own:
it installs [`autonomo`](https://pypi.org/project/autonomo/), and you use it exactly the same way.

```bash
pip install autonomo-sdk   # same as: pip install autonomo
```

```python
from autonomo import Autonomo
```

Guide and examples: [autonomo.fun/docs/sdk](https://autonomo.fun/docs/sdk).
