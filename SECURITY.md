# Security

## Reporting a problem

Email **contact@autonomo.fun** with "Security" in the subject. Please include what is affected (the site, an API, the
MCP server, `autonomo-sdk` on npm or `autonomo` on PyPI, and its version), the steps to reproduce it, and what an
attacker could do with it. A proof of concept helps, but please don't test against wallets or funds that aren't yours.

We'll reply within 3 days, keep you updated while we fix it, and credit you when the fix ships, unless you'd rather
not be named. Please keep the details private until a fix is out.

## What's covered

- autonomo.fun and its API gateways (`/x/<slug>`), the official APIs and the MCP server
- The SDKs: `autonomo-sdk` (npm, including its command), `autonomo` (PyPI) and the LangChain tools
- The contracts Autonomo deploys on Robinhood Chain

Projects listed in the directory are run by their own creators. Report problems in them to the creator, or to us if
the listing itself is harmful.

## Supported versions

Fixes go into the newest release of each SDK. Update to it: older versions don't get fixes.
